# Editing the website copy (no code required)

This is the everyday guide for changing text, headlines, FAQs, testimonials, and
the before/after slider images on **threaditate.com**. You do it all in Shopify's
visual **Theme Editor** — no code, no GitHub.

Your edits **save straight to the live site**, and they're safe: an automated job
backs them up to our code repo every night, and deploys are set up so a code push
will **never** overwrite what you change here.

---

## 1. Open the editor (use this exact link)

👉 **https://admin.shopify.com/store/string-ring-2/themes/182977593639/editor**

That opens the **Bubbly** theme — the live one. ⚠️ **Check the theme name in the
top bar says "Bubbly."** We have other themes (Horizon, Development) that look
empty — if a page looks blank, you're on the wrong theme; use the link above.

(Long way: Shopify admin → **Online Store → Themes** → the one marked **Live** →
**Customize**.)

## 2. Pick the page you want to edit

Top-center there's a **page dropdown** (it says "Home page" by default). Use it to
switch between:

- **Home page**
- **Products** → choose the kit (the product page)
- **Pages** → **Setup/How-To**, **FAQ**, **About**, **Contact**

## 3. Edit the text

1. In the **left sidebar** you'll see the page's **sections** (Hero, FAQ, etc.).
2. Click a section to open its fields, or click the small ▸ arrow to reveal its
   **blocks** (each FAQ, testimonial, feature card, and accordion is its own block —
   click into the block, not just the section).
3. Type your new text. The preview updates as you go.
4. Click **Save** (top right). That's it — it's live.

## Good to know

- **Blocks vs. sections:** repeated things (FAQs, testimonials, cards, accordions)
  are *blocks*. Click into the individual block to reach its text.
- **Accordion text** (Benefits / Features / Specs) is a small rich-text box — you can
  type freely; just be gentle with the bullet formatting.
- **Slider images:** in a "Before-after" section, click the before/after image block
  to swap the photo or change the label text.
- **Changes are live immediately.** There's no "publish later" step — Save = live.
- **You can't lose work.** Everything you save is backed up to our repo every night.
- **Please don't** delete whole sections or touch **Theme settings** (the gear/paint
  icons for fonts & colors) unless that's what you mean to do — text edits are safe;
  structural changes can shift the layout.
